# Темы для Tavern Gamejam

Выбор тем для Tavern Gamejam: голосования на выбывание.

Сайт: https://voltoran.github.io/friends-bracket/

## Как пользоваться

1. При первой настройке владелец открывает личную одноразовую ссылку и сам задаёт пароль администратора, минимум 8 символов. Затем достаточно нажать «Организатор» и ввести только пароль — почта, логин и письма не нужны. В панели есть «Сменить пароль» (с подтверждением текущего пароля).
2. В панели над сеткой нажмите «Создать голосование» и добавьте 4, 8 или 16 участников. Соседние строки становятся парами.
3. До старта можно переименовать категорию и участников.
4. Нажмите «Пригласить друзей», введите имя друга, создайте код и нажмите «Скопировать приглашение». Отправьте скопированный текст в мессенджере. Друг открывает сайт, нажимает «Войти по коду» и вводит код. Один код работает во всех открытых голосованиях. Скопируйте его сразу: исходный код не хранится в базе.
5. Нажмите «Открыть голосование». Друзья заходят по общей ссылке и вводят свои коды.
6. Нажмите «Завершить раунд», чтобы зафиксировать результаты и провести победителей дальше.
7. При ничьей можно собрать дополнительные голоса или начать переголосование. Оно затронет только пары с равным ненулевым счётом; прежние бюллетени сохранятся в базе.
8. Для удаления выберите голосование и нажмите «Удалить». Оно попадёт в корзину и перестанет принимать голоса. В «Корзине» можно восстановить его с участниками, результатами и прежним состоянием. Открытый турнир после восстановления снова принимает голоса.

Один код даёт один неизменяемый голос на пару в текущем голосовании. Передача кода другому человеку передаёт право голоса. Отключение кода запрещает новые голоса, но не удаляет уже учтённые.

Результаты и категории доступны всем по ссылке. Имена голосующих, коды и пароль не публикуются. Интерфейс обновляет результаты каждые 20 секунд; есть кнопка обновления. Сеанс администратора хранится в текущей вкладке браузера и действует до 12 часов. Выход отзывает его на сервере; смена пароля отзывает все прежние сеансы.

## Разработка и размещение

Статический HTML/CSS/JavaScript без сборки и зависимостей. Node.js нужен только для локального просмотра:

```sh
npm run dev
npm run check
npm test
```

Локальный адрес: http://127.0.0.1:4173. Локальная копия с рабочим config.js обращается к настоящей базе: не используйте её для пробных записей без отката.

GitHub Pages: ветка `master`, каталог `/ (root)`. `.nojekyll` отключает обработку Jekyll.

## База и доступ

- `config.js` содержит URL Supabase и публичный publishable key. Это не секрет; права проверяются на сервере.
- `schema.sql` — первоначальная схема, выполняется один раз в новом проекте Supabase; затем обязательно выполните `migration-003-admin-password.sql` для актуального входа.
- `migration-002-trash.sql` — обновление уже установленной первой версии: корзина и защита удалённых голосований. На основном сайте уже применено. Первоначальная схема также включает это изменение.
- Все таблицы находятся в закрытой схеме `bracket_private`, с RLS и без прямого доступа браузера.
- `migration-003-admin-password.sql` вводит пароль администратора, одноразовую настройку и сеансы. На основном сайте уже применена. Прежняя авторизация через email больше не даёт административных прав.
- Открыты чтение состояния, голосование, проверка статуса настройки и вход. Действия администратора выполняет функция `bracket_admin` со строго заданным списком команд и проверкой случайного токена сеанса. Прямой вызов прежних административных функций закрыт для браузера.
- Пароль хранится только как bcrypt-хеш с ценой 12. Ключ настройки и токены сеансов — только как SHA-256-хеши. Пароль не сохраняется в браузерном хранилище. После пяти неудачных попыток вход по паролю блокируется на 15 минут для всего сайта; существующие сеансы продолжают работать.
- Для нового экземпляра или восстановления забытого пароля владелец через SQL Editor выпускает новый случайный ключ настройки: пример ниже. Это действие доступно только владельцу базы. Ключ и пароль нельзя добавлять в GitHub.
- Персональные коды случайны, в базе хранятся только SHA-256 отпечатки.
- Голосование и завершение раунда блокируют одну запись категории, исключая гонку между записью голоса и подсчётом.
- Почтовая отправка и Supabase Auth для входа на сайт больше не используются. Друзьям регистрация не нужна.
- Пароли базы, service-role ключи и токены управления этому сайту не нужны и не должны находиться в клиентском коде.

## Проверки

`database-tests.sql` выполняет интеграционные проверки в транзакции с полным откатом тестовых записей: сетка, права организатора, закрытый черновик, повторные и неверные голоса, ничьи, переголосование с архивом, переходы в следующий раунд, финал и ограничения доступа гостя. Запускать через SQL Editor.

`admin-database-tests.sql` проверяет одноразовую настройку, ограничения попыток, пароль, права доступа, смену пароля, отзыв и истечение сеансов с полным откатом. `npm test` проверяет пользовательские сценарии с имитацией HTTP, без обращений к настоящей базе.

## Восстановление пароля владельцем базы

Выполните в SQL Editor своего проекта. Скрипт создаёт ссылку на 24 часа и заменяет предыдущую ссылку настройки. Текущий пароль и сеансы сохраняются до установки нового пароля по этой ссылке. Результат приватный: не пересылайте его друзьям и не сохраняйте в публичном репозитории.

```sql
with key as (select encode(extensions.gen_random_bytes(32),'hex') as value),
updated as (
  update bracket_private.admin_auth
  set setup_hash=bracket_private.secret_hash(key.value),
      setup_expires_at=now()+interval '24 hours'
  from key where singleton
  returning key.value
)
select 'https://voltoran.github.io/friends-bracket/#setup=' || value as owner_setup_link
from updated;
```

Для другого экземпляра замените адрес сайта. Ссылка открывает форму нового пароля; после сохранения она перестаёт работать, а все старые сеансы отзываются.

Функции поддерживают небольшие дружеские турниры. Публичные результаты видны во время голосования. Автоматического закрытия по таймеру нет — раунд завершает организатор.
